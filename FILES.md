# Структура проекта - Управление VPS Reg.ru

## 📁 Список файлов

### 🔧 Исполняемые скрипты

#### 1. power_on_vps.pl
**Назначение:** Базовый скрипт для включения VPS сервера  
**Сложность:** ⭐ Простой  
**Использование:**
- Отредактируйте переменные внутри скрипта
- Запустите: `perl power_on_vps.pl`

**Особенности:**
- Простая настройка через переменные в коде
- Использует service/resume API
- Базовая обработка ошибок
- Подходит для быстрого начала работы

---

#### 2. vps_manager.pl
**Назначение:** Расширенный менеджер VPS с параметрами командной строки  
**Сложность:** ⭐⭐⭐ Продвинутый  
**Использование:**
```bash
./vps_manager.pl -u login -p password [опции]
```

**Возможности:**
- Включение и выключение серверов (resume/suspend)
- Просмотр списка всех услуг (--list)
- Детальная информация об услуге (--info)
- Режим отладки (--debug)
- Гибкие параметры командной строки

**Функции API:**
- service/resume - включение
- service/suspend - выключение
- service/get_list - список услуг
- service/get_info - информация

---

#### 3. vps_config.pl
**Назначение:** Управление с поддержкой конфигурационных файлов  
**Сложность:** ⭐⭐ Средний  
**Использование:**
```bash
./vps_config.pl [--config путь] [опции]
```

**Преимущества:**
- Безопасное хранение учетных данных
- Автоматический поиск конфигов в стандартных местах
- Приоритет параметров: CLI > конфиг
- Проверка прав доступа к конфиг файлу

**Поиск конфигов:**
1. --config параметр
2. ~/.regru_config
3. ~/.config/regru/config.conf
4. ./regru_config.conf

---

#### 4. vps_status.pl
**Назначение:** Мониторинг статуса VPS серверов  
**Сложность:** ⭐⭐ Средний  
**Использование:**
```bash
./vps_status.pl -u login -p password [опции]
```

**Возможности:**
- Табличный вывод статуса всех VPS
- JSON вывод для автоматизации
- Режим непрерывного мониторинга (--watch)
- Фильтрация по service_id
- Статистика по статусам

**Режимы:**
- Одноразовый вывод (по умолчанию)
- Непрерывный мониторинг (--watch)
- JSON формат (--json)

## 📈 Типичные сценарии использования

### Сценарий 1: Первый запуск
```bash
make install
make setup-config
./vps_manager.pl -u user -p pass --list
./vps_config.pl -a resume
```

### Сценарий 2: Автоматизация через cron
```bash
# Создать конфиг
make setup-config

# Добавить в cron
0 9 * * * /path/to/vps_config.pl -a resume
0 22 * * * /path/to/vps_config.pl -a suspend
```

### Сценарий 3: Мониторинг
```bash
# Разовая проверка
./vps_status.pl -u user -p pass

# Непрерывный мониторинг
./vps_status.pl -u user -p pass --watch -i 30
```

### Сценарий 4: Интеграция со скриптами
```bash
# Получить JSON и обработать
./vps_status.pl -u user -p pass --json | \
  jq '.[] | select(.status=="suspended")'
```
