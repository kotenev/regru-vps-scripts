# Скрипты управления VPS серверами Reg.ru через API

Набор Perl скриптов для управления виртуальными серверами в личном кабинете cloud.reg.ru через официальное API v2.

## 📋 Описание

В комплект входят два скрипта:

1. **power_on_vps.pl** - простой скрипт для включения VPS сервера
2. **vps_manager.pl** - расширенный скрипт с дополнительными возможностями

## 🔧 Требования

### Системные требования

- Perl 5.10 или выше
- Доступ к CPAN для установки модулей

### Необходимые Perl модули

```bash
# Основной модуль для работы с API
cpan Regru::API

# Или используя cpanminus
cpanm Regru::API
```

Дополнительные модули (обычно уже установлены):
- `strict`
- `warnings`
- `utf8`
- `Data::Dumper`
- `Getopt::Long` (для расширенного скрипта)
- `Pod::Usage` (для расширенного скрипта)

## 📦 Установка

### Шаг 1: Установка Regru::API

```bash
# Используя CPAN
cpan Regru::API

# Или используя cpanminus (рекомендуется)
cpanm Regru::API

# На Ubuntu/Debian может потребоваться
sudo apt-get install libregru-api-perl
```

### Шаг 2: Загрузка скриптов

Скачайте скрипты и сделайте их исполняемыми:

```bash
chmod +x power_on_vps.pl
chmod +x vps_manager.pl
```

## 🚀 Использование

### Базовый скрипт (power_on_vps.pl)

#### Конфигурация

Отредактируйте скрипт и укажите ваши данные:

```perl
my $USERNAME = 'ваш_логин';          # Логин в Reg.ru
my $PASSWORD = 'ваш_пароль';         # Пароль
my $SERVICE_ID = '12345';            # ID вашего VPS
# или
my $DNAME = 'имя_сервера';          # Имя VPS
```

#### Запуск

```bash
perl power_on_vps.pl
```

### Расширенный скрипт (vps_manager.pl)

#### Просмотр списка всех услуг

```bash
perl vps_manager.pl \
    --username ваш_логин \
    --password ваш_пароль \
    --list
```

#### Включение сервера

По service_id:
```bash
perl vps_manager.pl \
    -u ваш_логин \
    -p ваш_пароль \
    --service-id 12345 \
    --action resume
```

По имени (dname):
```bash
perl vps_manager.pl \
    -u ваш_логин \
    -p ваш_пароль \
    --dname myserver.ru \
    --action start
```

#### Выключение сервера

```bash
perl vps_manager.pl \
    -u ваш_логин \
    -p ваш_пароль \
    -s 12345 \
    -a suspend
```

#### Просмотр информации об услуге

```bash
perl vps_manager.pl \
    -u ваш_логин \
    -p ваш_пароль \
    -s 12345 \
    --info
```

#### Режим отладки

```bash
perl vps_manager.pl \
    -u ваш_логин \
    -p ваш_пароль \
    -s 12345 \
    -a resume \
    --debug
```

## 📖 Параметры командной строки

### vps_manager.pl

| Параметр | Короткий | Описание |
|----------|----------|----------|
| `--username` | `-u` | Логин в Reg.ru (обязательно) |
| `--password` | `-p` | Пароль (обязательно) |
| `--service-id` | `-s` | ID услуги VPS |
| `--dname` | `-d` | Имя VPS сервера |
| `--action` | `-a` | Действие: resume/start/on или suspend/stop/off |
| `--list` | `-l` | Показать список услуг |
| `--info` | `-i` | Показать информацию об услуге |
| `--debug` | - | Режим отладки |
| `--help` | `-h` | Справка |

## 🔍 Как узнать service_id?

### Способ 1: Через скрипт

```bash
perl vps_manager.pl -u логин -p пароль --list
```

### Способ 2: Через простой скрипт

```perl
#!/usr/bin/env perl
use strict;
use warnings;
use Regru::API;
use Data::Dumper;

my $api = Regru::API->new(
    username => 'ваш_логин',
    password => 'ваш_пароль',
);

my $result = $api->service->get_list;
print Dumper($result->answer->{services});
```

### Способ 3: В личном кабинете

1. Войдите в личный кабинет Reg.ru
2. Перейдите в раздел "Услуги"
3. Выберите ваш VPS
4. service_id будет отображаться в URL или в деталях услуги

## ⚙️ Используемые функции API

Скрипты используют следующие функции Reg.ru API v2:

- `service/nop` - проверка доступности API
- `service/resume` - включение (возобновление) услуги
- `service/suspend` - выключение (приостановка) услуги
- `service/get_list` - получение списка услуг
- `service/get_info` - получение информации об услуге

## 🛡️ Безопасность

### Рекомендации по безопасности

1. **НЕ** храните пароли в открытом виде в скриптах на production
2. Используйте переменные окружения:

```bash
export REGRU_USERNAME="ваш_логин"
export REGRU_PASSWORD="ваш_пароль"
```

Модифицированный скрипт:
```perl
my $USERNAME = $ENV{REGRU_USERNAME} || die "Не установлен REGRU_USERNAME\n";
my $PASSWORD = $ENV{REGRU_PASSWORD} || die "Не установлен REGRU_PASSWORD\n";
```

3. Используйте файлы конфигурации с ограниченными правами:

```bash
chmod 600 ~/.regru_config
```

4. Рассмотрите использование аутентификации по сигнатуре (см. документацию API)

## 🐛 Обработка ошибок

### Типичные ошибки и их решение

#### SERVICE_NOT_FOUND
**Причина:** Указан неверный service_id или dname  
**Решение:** Проверьте ID услуги с помощью `--list`

#### SERVICE_NOT_SUSPENDED
**Причина:** Сервер уже включен  
**Решение:** Это нормально, сервер уже работает

#### SERVICE_EXPIRED
**Причина:** Срок действия услуги истек  
**Решение:** Продлите услугу в личном кабинете

#### Ошибка подключения к API
**Причина:** Неверные учетные данные или проблемы с сетью  
**Решение:** Проверьте логин/пароль и подключение к интернету
