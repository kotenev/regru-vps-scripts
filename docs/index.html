🚀 Управление VPS Reg.ru

Perl скрипты для управления виртуальными серверами через API v2

📦 Набор скриптов

⭐ Простой

power_on_vps.pl

Базовый скрипт для быстрого включения VPS сервера

  • Простая настройка
  • service/resume API
  • Обработка ошибок
⭐⭐ Средний

vps_config.pl

Управление с конфигурационными файлами

  • Безопасное хранение данных
  • Автопоиск конфигов
  • Включение/выключение
⭐⭐⭐ Продвинутый

vps_manager.pl

Полнофункциональный менеджер VPS

  • CLI параметры
  • Список услуг
  • Детальная информация
  • Режим отладки
⭐⭐ Средний

vps_status.pl

Мониторинг статуса серверов

  • Табличный вывод
  • JSON формат
  • Непрерывный мониторинг
  • Статистика

⚡ Быстрый старт

Установка за 3 минуты:

# 1. Установка зависимостей make install # 2. Настройка конфигурации make setup-config nano ~/.regru_config # 3. Использование ./vps_config.pl --action resume

🔧 Возможности

  • Включение и выключение VPS серверов
  • Просмотр списка всех услуг
  • Получение детальной информации
  • Мониторинг статуса в реальном времени
  • Безопасное хранение учетных данных
  • JSON вывод для автоматизации
  • Интеграция с cron для планирования
  • Поддержка нескольких VPS серверов

💡 Примеры использования

Включить сервер:

./vps_manager.pl -u логин -p пароль -s 12345 -a resume

Посмотреть статус всех серверов:

./vps_status.pl -u логин -p пароль

Непрерывный мониторинг:

./vps_status.pl -u логин -p пароль --watch --interval 30

Автоматизация через cron:

# Включать в 9:00, выключать в 22:00 0 9 * * * /path/to/vps_config.pl -a resume 0 22 * * * /path/to/vps_config.pl -a suspend

⚠️ Безопасность

Не забудьте установить правильные права доступа на конфигурационный файл:

chmod 600 ~/.regru_config

Никогда не добавляйте файлы с паролями в систему контроля версий!

✅ Требования

  • Perl 5.10 или выше
  • Модуль Regru::API (устанавливается автоматически)
  • Учетная запись на Reg.ru
  • Доступ к API Reg.ru
